# GetIt — 디자인 가이드

> 모바일 퍼스트. 한 손 조작. 매장에서 빠르게 확인하는 용도.

---

## 디자인 원칙

1. **속도 우선** — 한 탭에 필요한 정보만. 불필요한 장식 없음.
2. **한 손 조작** — 주요 버튼은 하단 엄지 영역에 배치.
3. **사진 중심** — 물건을 시각적으로 구분. 텍스트만으로는 매장에서 못 찾음.
4. **체크 피드백** — 구매 완료 시 명확한 시각적 변화 (흐림 + 취소선).

## 레이아웃

### 기본 구조

```
┌─────────────────────────┐
│  ← 뒤로    [페이지 제목]  │  ← 상단 바 (44px)
├─────────────────────────┤
│                         │
│                         │
│      콘텐츠 영역          │  ← 스크롤 가능
│                         │
│                         │
├─────────────────────────┤
│              [+ 추가]    │  ← FAB (우하단)
└─────────────────────────┘
```

### 뷰포트

- 기준: **375px** (iPhone SE/13 mini)
- max-width: **480px** (모바일 전용, 태블릿/데스크톱 미고려)
- 좌우 패딩: 16px
- Safe area 대응 (노치/홈바)

## 컴포넌트

### 1. 장소 카드 (홈)

```
┌─────────────────────────┐
│  캐널시티                  │  ← 장소명 (16px bold)
│  매장 3개 · 7/12 완료      │  ← 요약 (12px gray)
│  ████████░░ 58%           │  ← 진행률 바
└─────────────────────────┘
```

- 높이: auto (내용에 맞춤)
- 간격: 카드 간 12px
- 탭하면 장소 상세로 이동
- 우측 스와이프: 수정/삭제

### 2. 매장 카드 (장소 상세)

```
┌─────────────────────────┐
│  돈키호테          3F     │  ← 매장명 + 층수
│  5개 중 2개 완료          │  ← 진행률
│  ██████░░░░ 40%          │  ← 프로그레스 바
└─────────────────────────┘
```

### 3. 아이템 카드 (매장 상세)

```
┌───┬──────────────────────┐
│   │  포키 딸기맛           │  ← 아이템명
│ 📷│  ¥298 · must          │  ← 가격 + 우선순위
│   │  OO이 추천            │  ← 메모 (1줄)
├───┴──────────────────────┤
│  [  ] 체크                │  ← 체크 영역 (탭 영역 넓게)
└─────────────────────────┘
```

- 사진: 64x64px 썸네일 (좌측, rounded 8px)
- 체크 영역: 최소 44x44px 터치 영역
- 체크 시: 전체 카드 fade + 취소선 애니메이션 (200ms ease)
- 우선순위 'must': 오렌지 배지

### 4. FAB (Floating Action Button)

- 위치: 우하단 (right: 16px, bottom: 24px + safe area)
- 크기: 56x56px
- 색상: 프라이머리 블루
- 아이콘: + (흰색)
- 그림자: `0 4px 12px rgba(0,0,0,0.15)`

### 5. 아이템 추가 폼

```
┌─────────────────────────┐
│  [사진 영역 - 탭하여 업로드] │  ← 200x200, dashed border
├─────────────────────────┤
│  이름 *                   │  ← text input
│  가격 (엔)                │  ← number input
│  우선순위  [꼭 살 것] [여유] │  ← 토글 버튼
│  메모                     │  ← textarea (2줄)
├─────────────────────────┤
│        [저장]             │  ← 프라이머리 버튼, full-width
└─────────────────────────┘
```

- 사진 업로드: 카메라 or 갤러리 선택
- 필수 입력: 이름, 사진
- 저장 버튼: disabled until 필수 입력 완료

## 인터랙션

### 체크 토글
- 탭 → 즉시 체크 애니메이션 (낙관적 업데이트)
- 체크된 아이템: opacity 50% + 텍스트 취소선
- 체크된 아이템은 리스트 하단으로 이동 (300ms)

### 필터 탭
```
[ 전체(12) ] [ 미구매(7) ] [ 완료(5) ]
```
- 상단 고정 (sticky)
- 선택된 탭: 프라이머리 색상 밑줄

### 스와이프 액션
- 좌 스와이프: 삭제 (빨간 배경)
- 삭제 확인: "정말 삭제?" 토스트 (3초 Undo 가능)

### 페이지 전환
- 뒤로가기: 좌측 상단 화살표 (← )
- 전환 애니메이션: 슬라이드 (150ms)

## 오프라인 UX

### 온라인 상태
- 상단 바에 상태 표시 없음 (기본)

### 오프라인 상태
- 상단에 얇은 배너: "오프라인 모드 — 변경사항은 온라인 복귀 시 저장됩니다" (12px, 노란 배경)
- 리스트/사진: 캐싱된 데이터 정상 표시
- 체크 토글: 로컬에서 즉시 반영, 온라인 복귀 시 동기화
- 아이템 추가: 비활성화 (사진 업로드 불가)

## 상태별 화면

### 빈 상태 (Empty State)

장소/매장/아이템이 없을 때:
```
┌─────────────────────────┐
│                         │
│      (일러스트/이모지)     │
│                         │
│   "아직 장소가 없어요"     │
│   [+ 장소 추가하기]       │
│                         │
└─────────────────────────┘
```

### 로딩 상태

- 스켈레톤 UI (카드 모양 placeholder)
- 이미지: 회색 배경 + 로딩 shimmer

### 에러 상태

- "연결할 수 없습니다. 오프라인 데이터를 표시합니다."
- 재시도 버튼

## 애니메이션

| 동작 | 효과 | 시간 |
|------|------|------|
| 체크 토글 | fade + strikethrough | 200ms ease |
| 체크된 아이템 하단 이동 | translateY | 300ms ease-out |
| 카드 삭제 | slideLeft + fadeOut | 200ms |
| 페이지 전환 | slideRight/Left | 150ms |
| FAB 탭 | scale(0.95) → scale(1) | 100ms |
| 토스트 알림 | slideUp + fadeIn | 200ms |
